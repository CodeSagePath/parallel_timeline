# Parallel Timeline

`parallel_timeline` is a Flutter package for building parallel, dual-column
timeline interfaces. The package is currently scaffolded for development and
will add timeline models, layout widgets, painters, and examples in later
milestones.

## Planned Features

- Dual-column timeline layouts for planned and actual events.
- Time-based positioning for event cards.
- Custom timeline grid rendering.
- Example app for package consumers.

## Getting Started

Add the package to a Flutter project once a release is available on pub.dev:

```yaml
dependencies:
  parallel_timeline: ^0.0.1
```

During local development, use a path dependency:

```yaml
dependencies:
  parallel_timeline:
    path: ../parallel_timeline
```
